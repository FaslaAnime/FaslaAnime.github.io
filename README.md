# المصري للعالميه — PS4 Jailbreak Hub

دليل عربي (RTL) يجمع إصدارات تهكير السوني 4 من <bdi>1.76</bdi> وحتى <bdi>13.52</bdi> في صفحة واحدة، مع تركيز خاص على تهكير **Golden Hen / GoldHEN** للنسخة 9.00.

## المحتوى

- واجهة عربية RTL بتصميم داكن.
- بطاقة مميزة لـ Golden Hen (pOOBs4 / PSFree / GoldHEN).
- فهرس قابل للبحث والتصفية والترتيب لـ 19 إصدار.
- روابط مباشرة للمستودعات والهوستات العامة لأصحابها.
- دليل سريع وخطوات تحضير الجهاز.

## التشغيل محلياً

الموقع ثابت (HTML/CSS/JS بدون أي تبعيات) — افتح `index.html` مباشرة أو شغّل سيرفر بسيط:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.
