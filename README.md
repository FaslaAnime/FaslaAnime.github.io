# المصري للعالميه — تفعيل الجولد هين من متصفح السوني 4

موقع عربي (RTL) مش مجرد دليل روابط: محرك التهكير نفسه مستضاف جوه الريبو في مجلد `jb/`،
وزرار **فعّل الجولد هين** بيفتح المحرك مباشرة على متصفح السوني 4. مفيش تحويل لموقع المطور.

## اللي الموقع بيعمله فعلاً

- كشف متصفح السوني 4 عبر User-Agent وتحويله تلقائياً للمحرك المدمج.
- اختيار نطاق النسخة (6.00 حتى 13.52) بيحدّث رابط التفعيل بالسلسلة المناسبة `?chain=`.
- المحرك بيحدّد النسخة من الجهاز، يجهّز الكاش، ويروّح لصفحة السلسلة المطابقة.
- صفحات السلاسل والبايلودات (`core.js`, `jb.js`, `mem.js`, `goldhen.bin`, `hen.bin`, ...)
  كلها موجودة محلياً داخل `jb/`، فالتفعيل مش محتاج موقع خارجي.
- إضافة `?portal=1` لأي رابط بتعرض الصفحة التصميمية على السوني بدل التحويل التلقائي.

## النطاقات المدعومة

المحرك المدمج بيغطّي `6.00–12.02` و`12.50–13.52`. أشهر المسارات:

| النسخة | السلسلة |
| --- | --- |
| 6.00 – 8.52 | CSSFontFace + Lapse |
| 9.00 | PSFree + Lapse + GoldHEN |
| 9.60 | PSFree + Lapse |
| 10.00 – 11.02 | CSSFontFace + Lapse |
| 11.03 – 12.02 | Slopkit Lapse |
| 12.50 – 13.00 | Slopkit Netctrl |
| 13.02 – 13.52 | Slopkit Relapse |

الاختبارات المنشورة للمشروع الأصلي ذكرت النسخ 13.02 و13.04 و13.50 و13.52.
التفعيل الفعلي على جهاز حقيقي لازم يتجرب على السوني نفسه.

## التشغيل محلياً

الموقع ثابت (HTML/CSS/JS بدون تبعيات تثبيت)، بيفضّل سيرفر بسيط عشان المسارات النسبية تشتغل:

```bash
python -m http.server 8000
```

بعدين افتح `http://localhost:8000`. على السوني افتح نفس الرابط من متصفح الجهاز،
أو افتح `http://localhost:8000/jb/index.html` مباشرة.

## تنبيه

الدخول بـ PSN على جهاز عليه HEN قد يؤدي لحظر الحساب. استخدم حساب منفصل،
وخذ نسخة احتياطية من بياناتك قبل أي تعديل. الاستخدام على مسؤوليتك.
هذا المشروع كمان لا يملك جهازاً للتحقق من نجاح التفعيل على كل إصدار؛
الملفات والمسارات حقيقية ومختبرة كروابط ومسارات، والتجربة النهائية على الجهاز.
